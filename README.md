# Выбор оценки среднего уровня при выбросах с помощью машинного обучения

Код, данные и результаты исследования «Выбор оценки среднего уровня показателя при наличии выбросов в данных: подход на основе машинного обучения».

**Авторы:** Е.Ю. Шиманская, М.В. Соловьев, А.Е. Схведиани (Санкт-Петербургский политехнический университет Петра Великого).
Статья готовится к публикации; ссылка на неё появится здесь после выхода.

*English summary is given [below](#english-summary).*

## О чём исследование

Средняя арифметическая плохо описывает типичный уровень показателя, если в данных есть выбросы. Медиана и робастные оценки устойчивее, но на «чистых» данных теряют точность. Мы проверяем, может ли модель машинного обучения по характеристикам конкретной выборки выбирать оценку точнее, чем постоянное использование одной оценки и чем классическое адаптивное правило Хогга (1974).

**Оценки:** средняя, медиана, усечённая средняя (10 %), M-оценка Хьюбера (*c* = 1,345), оценка Ходжеса – Лемана.

**Характеристики выборки** (после центрирования по медиане и деления на MAD): log *n*, |асимметрия|, эксцесс, статистика *Q* Хогга, SD/MAD, доля наблюдений за «усами» диаграммы размаха, |средняя − медиана| / MAD.

**Модели:** случайный лес (основная), мультиномиальная логистическая регрессия, правило из двух условий с порогами, подобранными перебором.

## План эксперимента

Схема засорения Тьюки – Хьюбера, оценивается центр симметричного «чистого» распределения.

| Фактор | Значения |
|---|---|
| «Чистое» распределение | обучение: нормальное, Стьюдента (3 ст. св.); проверка переносимости: Лапласа, Стьюдента (2 ст. св.), логистическое |
| Объём выборки *n* | 10, 20, 50, 100, 300 |
| Доля выбросов *ε* | 0; 0,01; 0,05; 0,10; 0,20 |
| Расположение выбросов | симметричные; односторонние |
| Удалённость *k*, единиц масштаба | 3, 5, 10 |
| Сценариев / выборок в сценарии | 625 / 5 000 |

Качество — отношение MSE метода к MSE лучшей для сценария оценки («оракула»); перекрёстная проверка по сценариям (StratifiedGroupKFold, 5 частей). Дополнительно: среднее с равными весами сценариев без выбросов и с выбросами, доля серьёзных промахов (|ошибка| > 0,25 единицы масштаба), смещение при односторонних выбросах.

## Основные результаты

Нормальное распределение и распределение Стьюдента, 250 сценариев, перекрёстная проверка:

| Метод | Отношение MSE, в среднем | наибольшее | равные веса | Серьёзные промахи при выбросах, % |
|---|---|---|---|---|
| Средняя | 5,00 | 42,8 | 3,27 | 50,2 |
| Медиана | 1,11 | 1,60 | 1,21 | 29,7 |
| Оценка Хьюбера | 1,27 | 3,20 | 1,16 | 32,6 |
| Оценка Ходжеса – Лемана | 1,46 | 8,73 | 1,25 | 33,1 |
| Правило Хогга | 2,41 | 30,0 | 1,77 | 34,5 |
| Случайный лес | **1,05** | **1,52** | 1,10 | 29,2 |
| Правило из двух условий (мягкое) | 1,08 | 2,39 | **1,08** | 29,6 |

- Ни одна оценка не лучшая во всех условиях; правило Хогга при односторонних выбросах перестаёт работать.
- Случайный лес точнее любой фиксированной оценки и в среднем, и в худшем сценарии, но выигрыш у медианы невелик.
- На новых распределениях выигрыш сохраняется не везде: на распределениях Лапласа и Стьюдента с 2 ст. св. модель уступает медиане, на логистическом — точнее её.

**Правило из двух условий** (можно применять вручную):

> Если за «усами» диаграммы размаха не больше **5 %** наблюдений и |средняя − медиана| не больше **0,20 MAD** — оценка Хьюбера, иначе — медиана.

Это «осторожный» вариант; «мягкий» (16 % и 0,30 MAD) точнее на «чистых» данных, но может пропустить близкие односторонние выбросы. MAD здесь умножено на 1,483.

**Региональные данные за 2025 г.** (5 показателей по субъектам РФ): почти все процедуры выбирают медиану; невзвешенная средняя превышает её на 7–41 %. Полусинтетическая проверка (ошибки с лишним разрядом в 2–8 регионах) сдвигает среднюю на 21–87 %, медиану — на 0,7–5 %.

## Как воспроизвести

```bash
pip install -r requirements.txt
# полный расчёт (около часа)
python src/run2.py && python src/ml2.py && python src/rule2.py
python src/tab2.py && python src/bias2.py && python src/emp2.py
# только таблицы и рисунки по сохранённым результатам (секунды)
python src/tables2.py && python src/figs2.py && python src/figdata.py
```

Все генераторы случайных чисел зафиксированы, поэтому расчёт даёт те же числа. Большие промежуточные файлы (`store2.pkl`, `rf_*.pkl`) в репозиторий не включены — их создают `run2.py` и `ml2.py`.

## English summary

We study whether a machine learning model can choose an estimator of the typical level (mean, median, 10% trimmed mean, Huber and Hodges–Lehmann estimators) from sample characteristics more accurately than any fixed estimator and Hogg's adaptive rule. A Monte Carlo study with 625 contamination scenarios (5 distributions, *n* = 10–300, up to 20% outliers) shows that a random forest has an MSE on average 5% above the scenario-best estimator (median: 11%, Huber: 27%), with a worst case of 52% vs 60% for the median; Hogg's rule breaks down with one-sided outliers. A two-condition rule — Huber if at most 5% of observations lie beyond the boxplot whiskers and |mean − median| ≤ 0.20 MAD, otherwise the median — is nearly as accurate. For five indicators across Russian regions in 2025, almost all procedures select the median.
